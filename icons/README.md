# Icons Directory

This directory should contain the following PNG icon files:

- `icon16.png` - 16x16 pixels - Used in the extension toolbar
- `icon48.png` - 48x48 pixels - Used in the extension management page
- `icon128.png` - 128x128 pixels - Used in the Chrome Web Store

## Icon Requirements

- Format: PNG
- Transparent background recommended
- Should represent bookmarks/organization (e.g., folder, bookmark, sorting symbols)
- Follow Material Design principles for consistency with Chrome

## Temporary Solution

Since we cannot create actual PNG files in this environment, you can:

1. Use any online icon generator or image editor to create these icons
2. Search for free bookmark/folder icons on sites like:
   - Google Material Design Icons
   - Feather Icons
   - Heroicons
   - Font Awesome
3. Or temporarily use placeholder images until you can create custom icons

The extension will work without icons, but Chrome will show default placeholder icons.
